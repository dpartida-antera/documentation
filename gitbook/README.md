# Antera Documentation

Internal QA and Support documentation for the Antera order system. These guides describe intended system behavior and embed interactive tools you can use to confirm any case in seconds.

* [PO Shipping Address Guide](po-shipping-address.md) — which address every purchase order ships to.
* [Auto Allocation Guide](auto-allocation.md) — how booking an order splits each line into Stock, DropShip, and Backorder, including warehouse priority and parent-to-child inventory transfer.

{% hint style="info" %}
The interactive tools, flowcharts, and QA runners on these pages are embedded from the live Antera Documentation app. They run inside the page; nothing is installed.
{% endhint %}
